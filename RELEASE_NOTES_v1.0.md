# No.53 — Release v1.0 (2026-11-04)

**Rank-Unimodality Below Alternating Two-Valued Compositions**  
Ryutaro Yonezu — Independent Researcher

This is a **limited mathematical preprint** concerning the infinite family `(a,b)^m` for all integers `a>b>=1`, `m>=1` in generalized subword order. A duplicate-free recurrence and a computer-assisted all-parameter log-concavity certificate for `Q²` yield rank-unimodality of these principal ideals. No claim is made for arbitrary compositions.
